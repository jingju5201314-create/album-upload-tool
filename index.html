相册图片添加工具

拖入图片上传到图床 → 写入博客相册。提交后到博客页面 3 秒内连点左上角 logo 3 次刷新缓存即可显示
1令牌设置
高级选项（图床地址 / 上传渠道）
本图床当前启用的渠道：github、googledrive
2选择图片
把图片拖到这里，或 点击选择文件
也可以直接 Ctrl+V 粘贴剪贴板里的图片
还没有图片。拖入文件或粘贴链接后，会显示在这里。
3目标相册
填相册里某张图的链接 → 会跟随最新上传自动更新；填外部链接 → 固定用你填的
「相册卡片」为整个相册建一篇置顶文章：封面 = 最新上传的那张，正文按新 → 旧排成一行 4 张。只要卡片已存在，每次保存都会自动刷新它（张数 / 封面 / 照片列表），所以首页和相册永远对得上。「横幅」是把图片追加进首页顶部轮播。
「压缩重传」用来把已经传上去的大图重新压小：逐张下载原图 → 压缩 → 重传，原地替换地址，照片数量／顺序／标签／封面都不变，首页卡片和轮播里引用到的一起换。适合修复历史上没走压缩的图（常见 200 KB–1 MB 一张 → 压完通常几十 KB）。
4管理已有图片
点图片右上角的 ✕ 标记要删除的图（可多选），再点「删除已标记的图片」保存。删除前会弹窗确认
危险操作：删除整个相册
删除 albums/<相册名>/ 下的全部文件，并连同该相册生成的首页卡片文章一起删除（相册和所有图片都会从博客消失）。此操作不可恢复，需输入相册名二次确认
只删除 posts/album-<相册名>-*.md，不动相册本身。用于「相册已经删了、首页还留着一张卡片」这种情况
5上传日记
日记会保存到 diary/<日期>-<序号>/，正文和图片一次提交完成。上传后需刷新博客缓存生效
